# Phase 3 — Assiduité et notifications

**Fenêtre** : 18 jan → 19 fév 2027 (5 semaines, 2,5 sprints), puis pilote en production restreinte début mars. **Objectif** : un enseignant fait l'appel en moins de 60 secondes sur son téléphone ; le parent est prévenu en moins de 2 minutes. **Porte G3** (après 2 semaines de pilote) : ≥ 90 % des séances tenues ont un appel soumis ; délai médian soumission → notification < 2 min ; 0 incident d'isolation ; sondage enseignants : appel « plus rapide que le papier ».

**ADR mises en œuvre** : 0003, 0006, 0007. **Prérequis** : G2 ; fournisseur SMS contractualisé ; règles d'assiduité par défaut décidées (Phase 0).

## Risques spécifiques à la phase

- **Adoption enseignants** : si l'appel dépasse 60 s en test utilisateur, on simplifie avant d'ajouter quoi que ce soit ; la vie scolaire peut prendre le relais via `TAKE_ATTENDANCE_ANY`.
- **Coûts SMS** : push et in-app d'abord, agrégation, quotas dès le premier jour ; budget validé avec chaque pilote.
- **Délivrabilité SMS** : second agrégateur identifié en secours ; DLR surveillés.
- **Réseau dégradé** : brouillon hors ligne obligatoire (E1-S06) avant le pilote, pas « si on a le temps ».
- **Volumétrie des notifications** : une notification par événement, canal et destinataire ; index et plan de partitionnement prêts.
