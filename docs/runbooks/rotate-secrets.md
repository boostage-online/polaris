# Rotation des secrets

| Secret                                               | Fréquence                       | Procédure                                                                                                                                                                                                                                                                          |
| ---------------------------------------------------- | ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Clés JWT ES256                                       | 90 jours                        | `pnpm --filter @polaris/api keys:generate` → nouvelle paire avec nouveau `kid`. Déployer d'abord la **nouvelle clé publique en plus** de l'ancienne (fenêtre de double validité ≥ 15 min, durée d'un access token), puis la nouvelle clé privée, puis retirer l'ancienne publique. |
| Mots de passe DB (`polaris_app`, `polaris_platform`) | 180 jours ou départ d'un membre | `ALTER ROLE … PASSWORD`, mettre à jour les secrets du PaaS, redéploiement rolling.                                                                                                                                                                                                 |
| Secrets webhook providers                            | à chaque incident ou 12 mois    | Régénérer côté provider, mettre à jour `tenant_payment_configs` (chiffré), vérifier qu'un webhook de test passe.                                                                                                                                                                   |
| Clé maître KMS                                       | 12 mois                         | Rotation côté KMS (ré-enveloppement automatique des clés de données).                                                                                                                                                                                                              |
| Jetons CI (GHCR, PaaS)                               | 12 mois                         | Régénérer, remplacer dans les secrets GitHub.                                                                                                                                                                                                                                      |

Toute rotation est testée en staging le trimestre précédent et consignée (date, auteur, incident éventuel).
