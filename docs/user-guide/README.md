# Guide utilisateur Polaris

Documentation destinée aux établissements (administrateurs, direction, scolarité, finance, enseignants) et aux parents. Elle est rédigée pour être remise telle quelle, sans l'équipe technique. L'application est en **français** ; les montants sont en francs CFA (XOF) ; les heures sont celles de l'établissement.

| Guide                                                | Pour qui                          | Contenu                                                                                 |
| ---------------------------------------------------- | --------------------------------- | --------------------------------------------------------------------------------------- |
| [onboarding.md](./onboarding.md)                     | Administrateur de l'établissement | Mettre l'établissement en service en 2 heures avec l'assistant de démarrage             |
| [securite-du-compte.md](./securite-du-compte.md)     | Tout le personnel, Super Admin    | Mot de passe, double authentification (MFA), codes de récupération, appareils connectés |
| [donnees-personnelles.md](./donnees-personnelles.md) | Administrateur, parents           | Répondre à une demande d'accès ou d'effacement ; « Mes données » côté parent            |
| [faq.md](./faq.md)                                   | Tous                              | Questions fréquentes remontées par les pilotes                                          |

Les guides métier détaillés (appel, justificatifs, caisse, paiement en ligne, rapports) sont dans les écrans eux-mêmes (aide contextuelle) et seront regroupés ici à la Phase 8 (lancement).

Support : `support@polaris.app` (à créer) — joindre le **code de l'établissement** et, si possible, une capture d'écran. Le support peut, avec votre accord et pour 30 minutes au plus, ouvrir une **session de support** sur votre établissement ; vous le verrez à la bannière orange et dans le journal d'audit.
