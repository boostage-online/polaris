# Données personnelles : répondre aux demandes des familles

Votre établissement est **responsable** des données de ses élèves, parents et personnel ; Polaris les traite pour votre compte. L'application vous donne les outils pour répondre vous-même, en quelques minutes, aux demandes prévues par la loi (accès, copie, effacement). Menu : **Données personnelles** (rôle administrateur ; chaque action est journalisée).

## Un parent demande une copie de ses données ou de celles de son enfant

- **Le parent peut le faire seul** : dans son espace, « Mes enfants » → **Mes données** télécharge un fichier JSON avec son compte, ses enfants, leurs présences, leurs frais et paiements, ses notifications. Rien à faire de votre côté.
- **Depuis l'établissement** : ouvrez la fiche de l'élève (ou du tuteur) → **Exporter les données**, ou Données personnelles → saisissez l'identifiant → Exporter. Le fichier JSON est produit immédiatement ; remettez-le à la famille par un canal sûr. L'export est inscrit dans le **registre des demandes**.

Délai légal : 30 jours ; vous pouvez répondre le jour même.

## Une famille demande l'effacement

L'effacement s'appelle ici **anonymisation** : l'identité (nom, prénom, date de naissance, téléphone, e-mail, photo), les notes d'appel, les justificatifs et les notifications sont effacés ; les présences restent comptées sans nom (statistiques) ; les **pièces comptables** (créances, paiements, reçus) sont conservées 10 ans comme l'exige la comptabilité, rattachées à un identifiant anonyme.

Conditions :

- **Élève** : il doit avoir **quitté** l'établissement (inscription terminée). Par défaut l'application attend la fin du délai de conservation (5 ans après le départ) ; vous pouvez cocher « Forcer » si la famille le demande expressément — gardez sa demande écrite.
- **Tuteur** : il ne doit plus avoir d'enfant rattaché. Son compte parent est désactivé.

Marche à suivre : fiche → **Anonymiser** (ou Données personnelles → identifiant) → indiquez le **motif** (il est journalisé) → confirmez. L'opération est **irréversible** et apparaît dans le registre et le journal d'audit.

## Ce que l'application fait toute seule

- Chaque nuit, les élèves partis depuis plus de 5 ans et les tuteurs sans enfant inactifs depuis plus de 2 ans sont anonymisés automatiquement (durées modifiables dans Paramètres → Confidentialité).
- Les notifications de plus de 13 mois sont purgées.
- Le registre des demandes conserve qui a demandé quoi, quand et pourquoi.

## Ce qu'il faut faire de votre côté

- Informer les familles à l'inscription (modèle de mention dans votre règlement intérieur : « L'établissement utilise la plateforme Polaris pour le suivi de l'assiduité et des frais ; vous pouvez accéder à vos données et demander leur effacement auprès du secrétariat »).
- Désigner une personne qui reçoit les demandes.
- Ne pas exporter de données vers des fichiers personnels non protégés ; utiliser les rapports de l'application.

## En cas de fuite ou de doute

Un téléphone volé avec une session ouverte, un e-mail d'export envoyé à la mauvaise personne : prévenez immédiatement le support Polaris (`support@polaris.app`, objet « incident données ») et déconnectez l'appareil depuis Sécurité du compte. Polaris vous aidera à qualifier l'incident et, s'il le faut, à notifier l'autorité (APDP) sous 72 heures.
